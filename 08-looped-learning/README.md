# Looped Learning

Looped Learning captures how Research OS should improve from researcher reviews.

- `feedback-signals.jsonl`: review decisions with notes, interpreted into learning themes.
- `suggested-learnings.md`: Research OS-wide learning suggestions to review in the web UI.
- `active-learnings.md`: approved learning rules that future Codex/Cowork runs should apply.
- `learning-loop-state.json`: last Looped Learning handoff/run status for the dashboard.

Research OS does not learn silently. Review notes create suggested learnings first; approved learnings become active instructions for future analysis prompts.
