# Branding

Put local company branding files in this folder when you want Research OS outputs
or local scripts to use your own brand assets.

Recommended filenames:

```text
company-logo.png
company-footer.png
```

This folder is intentionally ignored by Git, Docker build context and share
packages except for this README and placeholder files. Do not commit private
company logos, internal artwork or licensed brand assets to the public Research
OS repository.

For public templates, reference the filename convention rather than including a
real company asset.
